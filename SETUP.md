# Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Run the test suite:
   ```bash
   npm run test:run
   ```
4. Build the production bundle:
   ```bash
   npm run build
   ```

## Environment

Copy `.env.example` to `.env` and adjust `VITE_API_BASE_URL` for your local or deployed API.
