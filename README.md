# Carpool Scheduler - Mobile Web App

A mobile-first web application for coordinating school pickup/drop-off carpools.

## 🚀 View the Prototype

The interactive prototype is live! Open it in your browser:

### Option 1: GitHub Raw File (Easiest)
**[View Prototype →](https://raw.githubusercontent.com/anshuman193/carpool-scheduler/main/index.html)**
- Just click the link and it will open in your browser

### Option 2: HTML Preview Service
**[View via HTMLPreview →](https://htmlpreview.github.io/?https://github.com/anshuman193/carpool-scheduler/blob/main/index.html)**

### Option 3: Local
1. Clone the repo: `git clone https://github.com/anshuman193/carpool-scheduler.git`
2. Open `index.html` in your browser

## 📱 Features

### Home Screen
- Daily duty notification
- Quick access to carpool groups
- Recent messages feed

### Calendar View
- Monthly schedule overview
- Carpool rotation schedule
- Swap request management

### Groups Management
- View all active carpools
- See member info & ratings
- Access group chat

### Find Carpools
- Smart matching based on schedule & location
- Filter by school, time, distance
- Join new carpool groups

### Messaging
- Direct & group chat
- Real-time notifications
- File sharing

### Profile & Settings
- Manage child information
- Notification preferences
- Privacy controls
- Payment methods

## 🎮 Interactive Prototype

The prototype includes all major screens with working navigation:

1. **Home** - Dashboard with today's duty and groups
2. **Calendar** - Monthly view with swap management
3. **Groups** - List and detail views
4. **Find Carpool** - Search and matching
5. **Chat** - Messages interface
6. **Menu** - Settings and profile

**How to use:**
- Tap the bottom tabs to navigate between screens
- Tap group names to see details
- Tap the back button (←) to go back
- All buttons are clickable
